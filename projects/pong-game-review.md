# Pong Game 项目体验记录

## 项目资料

- GitHub 项目：[Akki-jaiswal/pong-game](https://github.com/Akki-jaiswal/pong-game)
- 在线试玩：[Pong Game](https://akki-jaiswal.github.io/pong-game/)
- 项目类型：网页乒乓球游戏
- AI 类型：规则型电脑对手
- 当前状态：已完成第一次试玩

## 一句话介绍

这是一个可以在浏览器直接游玩的乒乓球小游戏，玩家需要对战由程序控制的 AI 对手。

## 第一次试玩记录

### 已体验内容

- 已体验简单模式
- 还没有体验普通模式
- 还没有体验困难模式
- 暂时无法判断三个难度的差别

### 发现的奇怪现象

有时候球看起来已经接触到底端，但游戏没有计算得分，而是继续运行。

目前还不能确定这是程序问题、游戏规则，还是画面显示造成的误解，需要再次测试并录屏确认。
